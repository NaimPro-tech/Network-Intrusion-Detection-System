১. নেটওয়ার্ক প্রোটোকল ও কমান্ড (Network Protocols & Commands)
TCP: Transmission Control Protocol
UDP: User Datagram Protocol
ICMP: Internet Control Message Protocol
HTTP: Hypertext Transfer Protocol
HTTPS: Hypertext Transfer Protocol SecureS
MTP: Simple Mail Transfer Protocol
FTP: File Transfer Protocol
VoIP: Voice over Internet Protocol
DNS: Domain Name System

২. নেটওয়ার্ক কানেকশন ও ফ্ল্যাগস (Connection & Flags)
SYN: Synchronize (সংযোগ শুরুর সংকেত)
ACK: Acknowledgment (প্রাপ্তিস্বীকার বা উত্তর)
FIN: Finish (সংযোগ সমাপ্তির সংকেত)
RST:Reset (সংযোগ জোরপূর্বক বাতিল করা)
SF: Normal Establishment and Termination
S0: Connection Attempt Seen, No Reply
REJ: Connection Attempt Rejected
RSTR: Responder Sent a Reset
SH: Originator Sent a SYN followed by a FIN
RSTO: Connection Established, Originator Aborted
S1: Connection Established, Not Terminated
RSTOS0: Originator Sent a SYN followed by a RST
S3: Connection Established, Responder Closed but no reply
S2: Connection Established, Originator Closed but no reply
OTH: Other / Midstream Traffic

৩. সাইবার সিকিউরিটি ও অ্যাটাক (Cybersecurity & Attacks)
DoS: Denial of Service
DDoS: Distributed Denial of Service
IDS: Intrusion Detection System
R2L: Remote to Local (দূরবর্তী অবস্থান থেকে স্থানীয় কম্পিউটারে অননুমোদিত প্রবেশের চেষ্টা)
U2R: User to Root (সাধারণ ইউজারের অ্যাকাউন্ট থেকে অ্যাডমিন বা রুট প্রিভিলেজ নেওয়ার চেষ্টা)
